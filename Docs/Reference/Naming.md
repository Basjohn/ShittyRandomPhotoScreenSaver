# Naming Reference

> Generated by `tools/naming_reference.py --write` from the registries; do not edit by hand. `tests/test_naming_reference.py` fails when this file differs from a fresh generation, and generation fails when a hand-written spelling or hazard no longer holds in the source.

- **Product names** (a mode's `display_name`, a transition label, a widget label) are what users and the operator say. Docs write the product name first with the id in backticks on first use in a section: Neon Lake (`shockwave_grid`), Spline Curve (`devcurve`).
- **Ids are persisted** (settings keys, preset folders, goldens, evidence folders) and are the code's name. Never rename one to match a product name; that needs a compatibility bridge (`Docs/Architecture/Persisted_Input_Compatibility.md`).
- To find every owner, search the id **and** every other spelling in its row; then check the grep hazards.

## Grep hazards

- `bubble_` (`bubble`) also matches `extruded_bubble_` (`extruded_bubble`) keys: search `\bbubble_` or `'bubble_`, never a bare substring
- `spectrum_` (`spectrum`) also matches `extruded_spectrum_` (`extruded_spectrum`) keys: search `\bspectrum_` or `'spectrum_`, never a bare substring
- "shockwave" is also Neon Lake's **onset-wave concept** (`ShockwaveEvent`, `SHOCKWAVE_WAVE_GLSL`, `SHOCKWAVE_DEPTH`), not only its old name: never rewrite `shockwave` to `neon_lake` mechanically
- "spline" is generic curve maths (Waveform Ribbon's `core/ribbon_geometry.py`, `core/ribbon_continuation.py`, `rendering/gl_programs/ribbon*.py`, and others); Spline Curve's own code is `devcurve*`
- "waveform" is also the captured PCM waveform that Oscilloscope draws; Waveform Ribbon's code is `waveform_ribbon*` plus `ui/studio/waveform_adapter.py`
- Waveform Ribbon's framed camera `SPEC` lives in `core/waveform_ribbon_scene.py`; `core/settings/waveform_ribbon_camera.py` holds only its floor and clipping contract
- "Glass" and "Acrylic" each name several systems (see Materials above): a card-material defect is never in `core/windows/dwm_blur.py`
