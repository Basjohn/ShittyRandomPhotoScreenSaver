# Documentation sweep, 6 November 2026

Dated audit snapshot (evidence only, not current authority). Scope: `Index.md`, `Spec.md`, `Docs/Contracts.md`,
`Docs/Guardrails.md`, `Docs/Guardrails/*`, `Docs/Guides/*`, `Docs/Architecture/*`, `Docs/Reference/*`,
`Docs/TestSuite.md`, `Future_Work.md`; `Current_Plan.md` read for context only.

**Method and limits.** Mechanical passes over every durable doc: every backticked or linked path checked against the
tracked tree; every backticked identifier of nine or more characters (snake_case, CamelCase, CONSTANT) checked against
source; documented numeric constants compared with source; documented CLI flags compared with `argparse`/script
source; `Current_Plan.md` section pointers and `File -> Section` pointers checked; every Historical Bug, Reference,
Guide and tool checked for routing from an index. Then targeted greps for each binding rule (env flags, timers,
fade/vanish, preset pins, visible windows, learned levels, diagnostics at rest, count-neutral catalogs). The corpus is
about 2.5 MB; `Docs/TestSuite.md`, `Docs/Reference/Extruded_Bubble/Investigation.md`, `Transitions.md` and the big
Guardrail documents were swept mechanically and by grep, **not read line by line**. Absent findings there mean "no
mechanical or keyword hit", not "proved clean". Off-limits files (Current_Plan, Visualizer_Studio, Waveform docs, the
Waveform sections of Visualizer_Reactivity_Authoring, Extruded_Bubble/*, and the Glass/Acrylic card-material passages)
were read for findings only and not edited.

## Decisions needed, ranked by impact

### D1. Source breaks the "no environment-variable flags" rule in six places (category 4, high)

Rule: Guardrails.md:22, Documentation_Maintenance.md:157, Linux_Guide.md:55 ("SRPSS itself is never configured through
environment variables"), Visualizer_Labs.md:43, Contracts.md:739 ("never ... env flags").

Source evidence:
- `main.py:1166`, `main.py:1203` `SRPSS_PROFILE_CPU` (already in Future_Work.md).
- `engine/display_manager.py:752` `SRPSS_MC_WINDOW_FLAGS` ("splash" selects the MC window role) - production behaviour switch, in no doc.
- `core/windows/reddit_helper_bridge.py:72` `SRPSS_DISABLE_REDDIT_HELPER_BRIDGE`.
- `core/logging/logger.py:851` `SRPSS_WIDGET_PERF_VERBOSE`, `:885` `SRPSS_DISABLE_LOGS`, `:891` `SRPSS_FORCE_LOGS`.
- `core/logging/logger.py:860` `SRPSS_FORCE_LOG_DIR` is the harness log-root hook (acknowledged `Linux_Plan.md:158`; used by `Docs/Reference/Harness_Index.md:748`, `tools/eb_live_phases.py:10`, `tools/linux_headless.py:64`, `tools/media_key_matrix_harness.py:603`).

Status: all but `PROFILE_CPU` were undocumented as violations; F8 now records them in Future_Work. Not fixed in code (report
only). Decision: promote the migration to `Current_Plan.md` (the lead owns it), and decide whether `SRPSS_FORCE_LOG_DIR`
is an allowed harness hook or must become a CLI/sidecar input, since Harness_Index tells agents to set it. Until then the
Linux_Guide sentence is aspirational.

### D3. Python startup warning: benign per one doc, open defect per the plan (category 1, medium)

`Docs/Guides/Python314_Cutover.md:13-19` explains `Failed to find real location of ...python.exe` as a Codex

### D4. Two warm-up mechanisms, one of them timer-driven (category 4/1, medium)

- `Spec.md:1003` (R138) and `engine/display_manager.py:4751-4772` (`_arm_next_idle_warm_step` with
  `IDLE_TRANSITION_WARM_STEP_SPACING_MS`) space idle transition warm-up with a 200 ms `ThreadManager.single_shot`.
- `Docs/Reference/Visualizer_Reference.md:318-322` spaces the Visualizer's `prepare_step` per rendered hidden frame
  (`PREPARE_SPACING_S = 0.03`, `rendering/quick/visualizer/render_host.py:73`), i.e. frame-piggybacked and timer-free.
- The operator's warm-up rule (gradual, on frames already rendered, no timers/polling) matches the second design, and
  "timers are a last resort" is a binding rule. The documented timer is a deliberate exception, but no doc justifies why
  transitions cannot use the frame-edge design. Decision: keep as accepted exception (add the reason to Spec.md:1003) or
  schedule a conversion.
