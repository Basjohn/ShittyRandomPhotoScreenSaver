# R-238: OpenGL unsigned uniform arrays dropped Bubble class words

**16 November 2026. Upload defect repaired and proved on official `c53e3fe27`; Bubble owner parity remains unaccepted.** Official run43947998973/token20261116_221602_505868 supplies the matching module. The current owner parity investigation, failed light control and remaining gates are in `Docs/Future_Work/Native_Bubble_Parity_Investigation.md`.

Bubble's four packed class words were correctly formed in native CPU memory but later unsigned-array words did not reach the OpenGL shader. A synthetic live R32F debug draw of 841 shader-read values on the pre-repair module found columns 835/836, the low/high halves of class word 1, were 0/0 instead of 34114/1 (word 99650). A serialized position mutation changed its expected slot; toggling word 1 bit 16 changed the expected word to 34114 but did not change its OpenGL output. Restoring the original record restored the original output. The corresponding Vulkan probe matched all 841 values for baseline, position and class mutations, and restoration, with no unexplained validation findings. See `.artifacts/evidence/native_core/n5_1_bubble/20261116_block_oracle/upload_opengl.json`, `upload_opengl.npz`, `upload_vulkan.json` and `upload_vulkan.npz`.

The reflected `uint[4]` has offset 192 and std140 stride 16. The CPU oracle matched 3,552 compared shader-read bytes, including class words, and detected a position mutation; it did not exercise GPU upload, per-pass target-size fields, shader evaluation or pixel parity. The independent CPU investigation retained exact baseline words `[1627389967, 99650, 0, 0]` and mutated words `[1627389967, 34114, 0, 0]`. Pinned Qt 6.12 OpenGL QRhi's unsigned scalar upload calls `glUniform1ui` once and ignores the reflected array dimension, unlike its depadded signed-int array branch. Thus a correct CPU block can still produce missing later unsigned words on OpenGL; this does not alone prove every owner-pixel residual has the same cause. Source and analysis: `20261116_block_oracle/UPLOAD_INVESTIGATION.md` and `upload_cpu_investigation.json`.

The repair migrates Bubble's four wire `u32` words to one canonical `uvec4`, preserving exact 32-bit representation. The shared native packer admits a matching unsigned record sequence into a vector with fail-closed type, shape and range checks. Portable shader admission refuses multi-element unsigned/bool uniform **leaf arrays**, including leaves nested within structs; an enclosing struct array by itself remains admitted, and storage buffers and generic CPU block packing are outside this restriction. The existing uint32-to-double-to-uint32 path is exact; no float32 coercion, wire-schema change or backend fallback is introduced. Focused regressions cover the shader owners, shape/range checks and positive storage, type and struct controls.
