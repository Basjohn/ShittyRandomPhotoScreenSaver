# SRPSS Reddit Helper build dependencies
# The Reddit helper is frozen with PyInstaller (not Nuitka) into an isolated
# on-disk bundle via scripts/venv/build_reddit_helper.ps1. It is effectively
# pure-stdlib at runtime -- the PyInstaller build explicitly excludes PySide6,
# winrt, numpy, PIL, sounddevice, pycaw and pytest, and the worker's only PySide6
# use is a lazy URL-open fallback (webbrowser is primary). These pins therefore
# cover only the PyInstaller build toolchain, installed into the shared repo-root
# .venv. Captured from the working Python 3.11.9 build environment.
